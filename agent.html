ກຳລັງກວດສະຖານະ...
ຍັງບໍ່ມີ API Key? ຕິດຕໍ່ສະໝັກແຈ້ງແອດມິນວ່າຕ້ອງການເປັນຕົວແທນ ແລ້ວຈະໄດ້ຮັບ API Key ສົ່ງໃຫ້
ກຳລັງໂຫຼດ...

ບອກຊື່ຜູ້ໃຊ້ຂອງທ່ານໃນເວັບ ແລະຈຳນວນທີ່ຄາດວ່າຈະຊື້ຕໍ່ອາທິດ ເພື່ອໃຫ້ແອດມິນຈັດລາຄາໃຫ້ທ່ານໄດ້ໄວຂຶ້ນ

ສິ່ງທີ່ຕົວແທນໄດ້ຮັບ

ລາຄາຕົວແທນຕັ້ງລາຄາແຍກຕາມສິນຄ້າ ຖືກກວ່າລາຄາປົກກະຕິ
ໃຊ້ໄດ້ທັນທີໃສ່ Key ແລ້ວ ລາຄາຕົວແທນມີຜົນທຸກການຊື້
ຮັບຄີອັດຕະໂນມັດຊື້ແລ້ວໄດ້ຄີ / ໂຄ້ດທັນທີ ບໍ່ຕ້ອງລໍແອດມິນ

ວິທີສະໝັກ (4 ຂັ້ນ)

  1. 1

    ຕິດຕໍ່ແອດມິນ

    ເລືອກຊ່ອງທາງຕິດຕໍ່ດ້ານເທິງ ແລ້ວແຈ້ງວ່າ ຢາກສະໝັກຕົວແທນ.

  2. 2

    ຮັບ API Key

    ແອດມິນຈະສົ່ງ API Key ໃຫ້ ໜ້າຕາຄ້າຍ EX-XXXXXXXX-XXXXXXXX ເກັບຮັກສາໄວ້ເປັນຄວາມລັບ.

  3. 3

    ໃສ່ Key ໃນໜ້ານີ້

    ເຂົ້າສູ່ລະບົບ ແລ້ວວາງ Key ໃນຊ່ອງດ້ານເທິງ ກົດ ເປີດໃຊ້ຕົວແທນ.

  4. 4

    ຊື້ໃນລາຄາຕົວແທນ

    ໄປຊື້ສິນຄ້າຕາມປົກກະຕິ ລະບົບຈະໃຊ້ ລາຄາຕົວແທນ ໃຫ້ອັດຕະໂນມັດ.

ຄຳຖາມທີ່ພົບບໍ່ຍາກ

API Key ໃຊ້ໄດ້ຈັກບັນຊີ?

1 Key ໃຊ້ໄດ້ກັບ 1 ບັນຊີ ເທົ່ານັ້ນ ເມື່ອເປີດໃຊ້ແລ້ວຈະຜູກກັບບັນຊີນັ້ນ ແລະບໍ່ສາມາດຍ້າຍໄປບັນຊີອື່ນເອງໄດ້.

ໃສ່ Key ແລ້ວຂຶ້ນວ່າ “ມີຄົນໃຊ້ແລ້ວ”?

ແປວ່າ Key ນີ້ຖືກເປີດໃຊ້ກັບບັນຊີໃດບັນຊີໜຶ່ງແລ້ວ ກະລຸນາຕິດຕໍ່ແອດມິນເພື່ອຂໍ Key ໃໝ່ ຫຼື ກວດວ່າທ່ານກຳລັງເຂົ້າບັນຊີທີ່ຖືກຕ້ອງ.

ລາຄາຕົວແທນເບິ່ງໄດ້ຢູ່ໃສ?

ເມື່ອເປັນຕົວແທນແລ້ວ ລາຄາຂອງທ່ານຈະສະແດງຢູ່ໃນກ່ອງ “ລາຄາຂອງຂ້ອຍ” ດ້ານເທິງຂອງໜ້ານີ້ ແລະໃນໜ້າ ຢືນຢັນການສັ່ງຊື້ ກ່ອນກົດຊື້.

ສິນຄ້າທີ່ບໍ່ມີລາຄາຕົວແທນ?

ສິນຄ້າທີ່ແອດມິນຍັງບໍ່ໄດ້ຕັ້ງລາຄາຕົວແທນ ຈະຊື້ໃນ ລາຄາປົກກະຕິ.

Key ຖືກປິດ ຫຼື ໃຊ້ບໍ່ໄດ້?

ເມື່ອແອດມິນປິດ Key ບັນຊີຂອງທ່ານຈະກັບໄປຊື້ໃນລາຄາປົກກະຕິ ກະລຸນາຕິດຕໍ່ແອດມິນເພື່ອສອບຖາມ.
